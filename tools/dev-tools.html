How to Use: Dev Tools

Site diagnostics and maintenance utilities, visible only on the account actively developing this site.

  • Live consistency check — fetches every tool page right now and checks each one for the login gate, a CSP, the PWA manifest link, a matching styles.css version, and that manifest.json's own URLs all have the /tools/ prefix. The same checks run automatically in GitHub Actions on every push; this just lets you run them on demand.
  • Session & sync — who's logged in on this device, the last sync result, and manual Push/Pull buttons to force a sync right now.
  • Local data snapshot — every th_/rd_ key in this browser, its size, and an expandable raw view of its actual contents. This device only.
  • Service worker & cache — registration status, what's cached, and a one-click clear if something seems stale.
  • Client errors — the last 20 JavaScript errors captured on this device, across every tool page.
  • Appliance Wiki health — quick counts: brands, models, issues, and the verified/logged-by-you split.
  • Device info — browser, screen size, and online status — useful when something behaves differently on phone vs. computer.
  • Known issues — still-open items from the last security audit, checkable so they don't get lost.
  • Latest deploy — the most recent GitHub Actions run, pulled live.
  • Quick links — the repo, its Actions history, the Supabase dashboard, and the live site.
