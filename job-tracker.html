How to Use: Job Tracker

This page combines five related tools into tabs. Data lives in this browser, and also syncs to the cloud if you've set that up on the Workspace page.

  • Jobs — add a job with priority/status/due date, sort by date or priority, hide completed jobs, or tap "Advance Status" to cycle Not Started → In Progress → Done.
  • Cost Lookup — type in hours and parts cost to see the standard price instantly. Check "First-time client" to see the discounted price too. Save frequent job types under "Price Reference" and tap one anytime to reload it.
  • Expenses — log expenses or mileage, now with vendor, payment method, and an optional link to a specific job. Mileage rate lives right next to the Miles field since it's only relevant for mileage entries. Export CSV anytime for a backup or for taxes.
  • Contacts — a quick address book for vendors, suppliers, or recurring clients.
  • Notes — keep as many separate, named notes as you want. Click one on the left to open it, or start a new one. Saves automatically as you type.

Set up Cloud Sync once on the Workspace page's "?" help, and this data follows you to any device using the same sync code.
