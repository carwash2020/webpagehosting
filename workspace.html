How to Use: Workspace

This is the home base for every internal tool — bookmark this one page rather than any individual tool.

  • Job Tracker — jobs, cost lookup, expenses & mileage, contacts, and notes, all in one tabbed page.
  • Contact Card Generator — turn a name/phone/email into a file that saves straight into your phone's contacts.
  • Route Planner — queue up today's addresses, get one link that opens the whole route in Google Maps.
  • Invoice Generator — fill in job details, download a branded PDF invoice with your Venmo QR built in.
  • Review Request Sender — after a job, generate a ready-to-send review-request text message.

Every tool has its own "?" button with instructions specific to that page. Nothing typed into any of these tools is sent to a server — data either stays in this browser (Job Tracker) or only exists in a file you download (Contact Card, Invoice Generator).
